§ 04 Component anatomy The three components that recur everywhere
Header

Brand + nav

  • Persistent .meta-strip above the header: mono 12px, dot+accent on left, updated date on right. Hairline below.
  • Brand: serif 600/22px wordmark + italic · glyph in accent, with brand__sub mono caption.
  • Nav: JetBrains Mono 13px, uppercase, +0.04em. Current page gets a 1px accent underline.
  • 1px --rule bottom border; same gutter as content (clamp(20px, 4vw, 48px)).
Post / project row · card

The numbered row

  • Grid: 48px (num) | 1fr (title+dek) | tag | 88px (date). Hover tints row with --accent-soft.
  • Index: mono 13px, tabular nums, muted. Always 3-digit (001, P/01).
  • Title: Source Serif 22px / weight 500 / -0.01em. Link inherits color; hover → accent.
  • Dek: serif 15px / muted / max 60ch. Date is mono 12px tabular, right-aligned.
  • Project cards inherit the same idiom but render in a 2-col gutter-as-rule grid.
Footer

3-column colophon

  • 3 equal columns: Elsewhere, Reading recently, Colophon. Each header is mono 12px uppercase muted.
  • List items use a name / k pattern (label + tabular mono key) — same visual as the dl on the homepage hero.
  • Bottom strip: mono 12px, copyright left, domain right, separated by a soft hairline.
  • Stacks to a single column under 760px; preserve the name/k alignment.
§ 05 Custom CSS worth preserving Tiny details that hold the whole look together 
/* selection — accent ink on cream, never default blue */
::selection { background: #1c3d6e; color: #f6f2e8; }

/* focus ring — accent, generous offset, soft radius */
:focus-visible {
  outline: 2px solid #1c3d6e;
  outline-offset: 3px;
  border-radius: 2px;
}

/* tabular numerals everywhere we list a number */
.num, time, td.num, .post-row__date, .changelog .v, .stat__num {
  font-feature-settings: "tnum";
  font-variant-numeric: tabular-nums;
}

/* drop cap on first paragraph of a post */
.post-body p.lede::first-letter {
  font-family: "Source Serif 4", serif;
  font-weight: 500;
  font-size: 4.2em;
  float: left;
  line-height: 0.88;
  padding: 4px 10px 0 0;
  margin-top: 4px;
  color: #1c3d6e;
}

/* faint paper grain — body bg, two radial tints */
body {
  background:
    radial-gradient(circle at 12% 18%, rgba(28,61,110,0.015) 0, transparent 60%),
    radial-gradient(circle at 88% 82%, rgba(28,61,110,0.018) 0, transparent 55%),
    #f6f2e8;
}

/* italic glyph in brand mark — the one decorative beat */
.brand__mark .glyph {
  font-family: "Source Serif 4", serif;
  font-style: italic;
  font-weight: 400;
  color: #1c3d6e;
}

/* enable Source Serif's stylistic set + oldstyle figures in prose */
html { font-feature-settings: "ss01", "onum", "kern"; }

§ 06 Implementation notes For the rebuilding engineer
Accessibility

Contrast & focus

  • All body/headline pairs against --bg exceed WCAG AAA (11–15:1).
  • Muted text (#6E655A) is AA at body sizes; never use it below 14px.
  • Focus ring is a real visible outline, not a box-shadow hack. Don’t remove on click.
  • Nav current-page indicator is both color and underline (don’t collapse to color alone).
Responsiveness

Three breakpoints, no more

  • 1080px — post body collapses marginalia + toc into stacked rails.
  • 860px — homepage hero stacks; post-rows collapse meta under title.
  • 560px — stat strip stacks vertically; spec sheet labels narrow to 80px.
  • Otherwise: gutter and type scale are clamp()-driven and fluid.
Performance

What to keep simple

  • Only the 3 font families. Don’t add a fourth without a reason.
  • No JS required for any layout. Hovers + focus are CSS-only.
  • Subset Source Serif to Latin if shipping self-hosted (the optical-size axis is what we’re paying for, keep it).
  • No animations beyond color/background 120ms ease on links and rows.
